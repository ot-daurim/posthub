# PostHub MVP Use Cases

## Гость (неавторизованный пользователь)

### UC-001 Просмотр публикаций

Пользователь может:

* просматривать общую ленту публикаций;
* открывать страницу публикации;
* просматривать профили авторов;
* просматривать комментарии к публикациям.

---

### UC-002 Поиск и фильтрация

Пользователь может:

* искать публикации;
* искать пользователей;
* применять фильтры к публикациям.

---

### UC-003 Регистрация

Пользователь может создать аккаунт.

---

### UC-004 Авторизация

Пользователь может войти в систему.

---

## Авторизованный пользователь

### UC-005 Управление профилем

Пользователь может:

* просматривать свой профиль;
* редактировать свой профиль;
* изменять описание профиля;
* изменять отображаемое имя;
* изменять аватар.

---

### UC-006 Создание публикации

Пользователь может:

* создать публикацию;
* прикрепить изображение;
* опубликовать публикацию.

---

### UC-007 Управление своими публикациями

Пользователь может:

* редактировать свои публикации;
* удалять свои публикации.

Пользователь не может изменять публикации других пользователей.

---

### UC-008 Работа с комментариями

Пользователь может:

* создавать комментарии;
* редактировать свои комментарии;
* удалять свои комментарии.

Пользователь не может изменять комментарии других пользователей.

---

### UC-009 Работа с лайками

Пользователь может:

* поставить лайк публикации;
* убрать лайк публикации.

---

### UC-010 Работа с сохраненными публикациями

Пользователь может:

* сохранить публикацию;
* удалить публикацию из сохраненных;
* просматривать список сохраненных публикаций.

---

### UC-011 Подписки

Пользователь может:

* подписаться на другого пользователя;
* отписаться от другого пользователя;
* просматривать подписчиков;
* просматривать подписки.

---

### UC-012 Лента подписок

Пользователь может просматривать публикации пользователей, на которых подписан.

---

### UC-013 Общая лента

Пользователь может просматривать все опубликованные публикации платформы.
