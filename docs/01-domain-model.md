# PostHub Domain Model (MVP)

## Назначение системы

PostHub — социальная платформа для разработчиков, исследователей, студентов, инженеров и специалистов, где пользователи могут публиковать контент, взаимодействовать друг с другом и формировать профессиональное сообщество.

---

# Основные сущности

## User

Представляет зарегистрированного пользователя платформы.

Пользователь может:

* создавать публикации;
* редактировать свой профиль;
* оставлять комментарии;
* ставить лайки;
* сохранять публикации;
* подписываться на других пользователей.

---

## Publication

Основная сущность контента платформы.

Публикация принадлежит одному пользователю.

Публикация может содержать:

* заголовок;
* текстовый контент;
* изображение.

На текущем этапе поддерживается тип:

* POST

В будущем планируются:

* ARTICLE
* VACANCY
* PROBLEM
* RESEARCH
* PROJECT_UPDATE

---

## Comment

Комментарий пользователя к публикации.

Комментарий:

* принадлежит пользователю;
* принадлежит публикации.

В MVP поддерживаются только комментарии первого уровня.

---

## PublicationLike

Лайк публикации.

Представляет факт того, что пользователь поставил лайк публикации.

Один пользователь может поставить только один лайк одной публикации.

---

## SavedPublication

Сохраненная публикация пользователя.

Представляет факт добавления публикации в личные закладки пользователя.

Один пользователь может сохранить публикацию только один раз.

---

## Follow

Подписка одного пользователя на другого пользователя.

Подписка является направленной связью.

Пример:

Пользователь А подписан на Пользователя Б.

Взаимная подписка возникает автоматически, если Пользователь Б также подписан на Пользователя А.

---

# Связи между сущностями

User (1) -------- (N) Publication

User (1) -------- (N) Comment

Publication (1) -------- (N) Comment

User (1) -------- (N) PublicationLike

Publication (1) -------- (N) PublicationLike

User (1) -------- (N) SavedPublication

Publication (1) -------- (N) SavedPublication

User (1) -------- (N) Follow (follower)

User (1) -------- (N) Follow (following)

---

# Ограничения доменной модели

## Публикации

Публикация должна иметь:

* автора;
* заголовок;
* контент.

---

## Комментарии

Комментарий должен принадлежать:

* пользователю;
* публикации.

---

## Лайки

Пользователь не может поставить несколько лайков одной публикации.

---

## Закладки

Пользователь не может сохранить одну публикацию несколько раз.

---

## Подписки

Пользователь не может подписаться на самого себя.

Пользователь не может подписаться на одного пользователя несколько раз.

---

# Будущие расширения

Планируется поддержка:

* статей;
* вакансий;
* проблем;
* исследовательских публикаций;
* проектов;
* команд;
* уведомлений;
* личных сообщений;
* рекомендательной системы.
